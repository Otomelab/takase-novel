# 境界の手前

高瀬航（32・整体師兼パーソナルトレーナー）と小野寺由衣（29・会社員）の、最終枠一夜だけのノベルです。ビルドは要りません。`index.html` をブラウザで開いてください。

## 遊び方

クリック、または Enter / Space で文章を進めます。選択肢は由衣の行動です。画面左上の **理性** は高瀬の自制、右上の **BPM** は由衣の脈です。♥ を押すと、公式カルテと高瀬の裏メモ（裏カルテ）が開きます。数値も、メモの文面も、その場の状態で変わります。

BGM は低いうなりと、脈に合わせた心音です。オートは文章を自動で送ります。

## パラメータ

| 名前 | 意味 | 何が変わるか |
| --- | --- | --- |
| 脈（BPM） | 由衣の心拍 | 高瀬が脈を隠さなくなる。120以上で、彼の手首を取り返す選択肢が出る |
| 理性 | 高瀬の自制（0–100） | 口調、吐息が半秒漏れるかどうか、終わり |
| 越えた | 由衣が自分から境界を踏んだ量 | 「預けたい」「運動のせいじゃない」「触れてほしい」、脈を返す |
| 引いた | 由衣が距離を取った量 | 手首を抜く、帰ると言う、ベッドで止める |

理性が **62未満** のままベッドの深いところ（小胸筋）に入ると、吐息と半秒だけ熱が漏れます（slip）。高瀬は自分で手を小胸筋へ戻し、「今のは、施術じゃない」と認めます。由衣がそこで「やめてください」と言えば、語尾と同時に手は離れます。来なくなる理由は、先に熱が漏れたのを見られたことです。

判定そのものは `js/branching.js` にあり、`node js/simulate.js` が全60経路を歩いて3つの終わりへ届くことを確認します。

## 理性と口調

高瀬の台詞は、理性の高さで同じ意味のまま崩れます。名前つきの筋肉と動脈は、崩れたあとも残ります。丁寧語が死んでも、触る理由だけは解剖のままです。

| 理性 | 口調 | 聞こえ方 |
| --- | --- | --- |
| 80以上 | 丁寧語 | 「橈骨動脈、ここで触れます。10秒だけ数えますね」 |
| 64–79 | 欠け | 「橈骨動脈、ここです。……10秒だけ」 |
| 46–63 | 混線 | 「俺、数えるんで」と漏れて、です、に戻そうとする |
| 45以下 | タメ口 | 「10秒も要らないだろ」 |

裏カルテの非公開メモは、最初から高瀬の素の口調です。表の口がどこまで持ったかも、そこに書かれます。

## 脈を返す

彼が由衣の橈骨動脈を測ったあと、**脈が120以上のときだけ**「彼の左手首を取る。親指を、橈骨動脈に当てる」が出ます。意地を張り続けて脈が上がらない夜には、この選択肢自体がありません。

返したあとでベッドに残ると「寸前」に近づき、返したまま帰ると「空いた枠」になります。返さずに言葉だけで越えて、ベッドで力を抜くルートでも「寸前」には届きます。

## 三つの終わり

規則はひとつです。客が自分の足で越えてくるまで、高瀬からは動かない。

**店じまいの笑顔**（普通のさよなら）

- 鍛えに来た → 手首を預ける → ベッドに横たわる → 息を吐いて力を抜く
- 理性は最後まで比較的残る。口調は丁寧語から、語尾が欠けるところまで。名前のついた筋肉だけで終えて、また来いと送る
- 「触れてほしい」と言っても理性が58より上なら、聞こえたまま越えない。この終わりの別の顔

**寸前**（理性が割れて、暗転）

- 預けたい → 手首を預ける → 脈が120を超えているので、彼の橈骨動脈を取り返す → ベッドに残る → 力を抜く
- あるいは、脈を返さなくても「触れてほしい」と言ってベッドで力を抜く（理性が58以下のとき）
- 越えたのは由衣の指か、由衣の言葉。唇の直前で照明が落ちる。それより先は書かない

**空いた枠**（彼女が来なくなる）

- 鍛えに来た → 手首を抜く → 「今日は大丈夫」と帰る。彼は最後まで丁寧語のまま。礼だけが深くて、翌週の枠は空く
- 熱を上げたあとベッドで「やめてください」。吐息と半秒が先に漏れた夜は、拒まれた瞬間に手を離しても、来なくなる
- 脈を返したのに、ベッドに入らず帰る。追わない
